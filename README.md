## Sobre el proyecto

Sitio comercial para Fidel Bonilla, asesor automotriz: compra y venta de vehículos, trámites vehiculares (traspasos, matriculación, certificados ANT) y consignación. Construido como un recorrido de scroll con video y secuencias de fotogramas por sección.

## Tecnologías

- HTML5 / CSS3 / JavaScript vanilla — sin frameworks ni build step
- Secuencias de frames + video para el efecto de scroll
- Contacto directo por WhatsApp

## Ver el código localmente

```bash
git clone https://github.com/fleremiasflemin20-maker/fidel-bonilla-autos.git
cd fidel-bonilla-autos
npx serve .
```
